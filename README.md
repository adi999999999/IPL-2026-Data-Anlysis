# 🏏 IPL 2026 Data Analysis

## 📌 Project Overview

This project performs an exploratory data analysis of IPL 2026 ball-by-ball delivery data using Python.

The objective is to analyze player performance, team performance, scoring patterns, bowling statistics, match situations, and other important insights from the dataset.

The project demonstrates practical skills in data cleaning, data manipulation, exploratory data analysis, statistical analysis, and data visualization.

---

## 🎯 Objectives

The main objectives of this project are:

* Analyze IPL match and delivery-level data
* Identify top-performing batsmen
* Analyze bowling performance
* Compare team performances
* Analyze scoring patterns
* Identify boundary and run-scoring trends
* Study wicket-taking patterns
* Create meaningful data visualizations
* Extract actionable insights from the dataset

## 📊 Analysis Performed

The project includes analysis of:

### Batting Analysis

* Total runs scored
* Batting average
* Strike rate
* Boundary analysis
* Top run scorers
* Player-wise performance

### Bowling Analysis

* Total wickets
* Economy rate
* Bowling average
* Wicket-taking performance
* Bowler comparison

### Team Analysis

* Team-wise runs
* Team scoring patterns
* Wickets lost
* Boundary statistics
* Match performance comparison

### Visualization

The analysis uses:

* Bar charts
* Line charts
* Histograms
* Count plots
* Box plots
* Heatmaps
* Distribution plots

The analysis identifies important patterns from the IPL 2026 dataset, including:
