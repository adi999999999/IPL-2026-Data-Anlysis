# IPL 2026 Data Analysis

## Project Overview
Exploratory Data Analysis of IPL 2026 delivery-level data using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
IPL 2026 ball-by-ball delivery data.

## Analysis
- Team performance
- Batting performance
- Bowling performance
- Strike rate
- Economy rate
- Boundary analysis
- Extras
- Venue analysis
- Powerplay, middle overs and death overs
- Correlation analysis
